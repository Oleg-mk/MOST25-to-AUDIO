# Комплект слухача MOST25 to AUDIO

Тут лежить усе, щоб зробити слухача й записати з ним машину, без решти репозиторію. Слухач стоїть
у кільці MOST25 і нічого в нього не каже. Він чує звук і команди головного пристрою й віддає
звук на TDM, I2S, S/PDIF і лінійний вихід. Коли дозволено, він підмішує телефон (Bluetooth) або
вхід TOSLINK у джерело AUX машини. У машині ще не перевірено.

Плата — v2.0: схема v1.6 з кількома доданими резисторами й фільтрами, на платі 98 x 60 мм, що
входить в алюмінієву трубу 80x30x2 з двома друкованими кришками. Одна плата дає три збірки: min,
mid і max.

| Папка | Що всередині |
|---|---|
| `1_boards/` | замовлення плат на JLCPCB з монтажем SMD з обох боків, три збірки; деталі для ручного монтажу; труба й кришки для друку; схема, креслення монтажу, перевірки перед живленням, складання в трубу |
| `2_flash/` | прошивка FPGA (`fpga/listener.fs`) для Tang Nano 20K і прошивка хоста (`esp32/*.bin`) для ESP32-DevKitC-VIE, і як записати кожну з Windows або macOS |
| `3_laptop/` | запис консолі хоста в машині й розбір удома, для Windows 10/11 і macOS (і на Apple Silicon) |

## Порядок

1. **Плати.** Замовити за `1_boards/README.md`. Окремо купити деталі для ручного монтажу й трубу,
   надрукувати кришки.
2. **Прошивки.** Ще до запаювання модулів записати `listener.fs` у Tang Nano 20K, а прошивку
   хоста в ESP32-DevKitC-VIE, кожен модуль через його власний USB (`2_flash/README.md`). USB-C
   модуля FPGA після монтажу закривають гнізда RCA.
3. **Монтаж, перше живлення на столі, складання в трубу:** `1_boards/README.md`.
4. **Машина, по кроках** (README репозиторію, «Bring-up, in this order»): спершу лише
   прослуховування й захоплення лінії, далі регенерація, далі підмішування. Кожен крок іде з
   записом (`3_laptop/README.md`).

## Звідки ці файли

Комплект збирає `tools/make_kit.py` з репозиторію. Файли плат, кришок, прошивки й програми є
копіями, а пояснення (`README.md`) і файли запуску написано вручну. `check_all.py` падає, якщо копія
розійшлася з джерелом, якщо в комплекті лишився зайвий файл або якщо прошивка старша за свої
джерела. З якого коміту зібрано кожну прошивку, записано в `2_flash/fpga/BUILD.txt` і
`2_flash/esp32/BUILD.txt`.

Повні описи лежать у репозиторії:
- `README.md`: рішення і їхні причини, порядок запуску;
- `listener_hw2/fab/README.md`: плата v2.0 і три збірки;
- `listener_hw2/caps/README.md`: труба й кришки;
- `listener_gw/README.md`: FPGA;
- `listener_fw/README.md`: хост і запис.

Попередня плата, v1.6 (два шари, 123.55 x 78.9 мм, без труби), лежить у `listener_hw/` разом зі
своїм пакетом для замовлення, `listener_hw/fab`. У комплект вона більше не входить.
